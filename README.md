With strong competencies in the **MERN Stack** (MongoDB, Express.js, React, Node.js) and core computer science fundamentals, I specialize in architecting clean RESTful services, scalable databases, and reactive frontend experiences.

- ⚙️ **Core Engineering:** Modern JavaScript (ES6+), Component-Driven Development, RESTful API design, and Database Modeling.
- 💡 **Foundational CS:** Solid problem-solving foundations across **JavaScript, C, C++, Java, and Python**.
- 🤖 **Systems & IoT:** Hands-on hardware interfacing and automation with **Raspberry Pi, Arduino, and Home Assistant**.
- 🎯 **Commitment:** Clean architecture, performant code, continuous learning, and test-driven quality.
